# District-Wise Operational Analytics Dashboard

A lightweight, high-performance static analytics dashboard providing granular operational metrics across key districts (Arwal, Aurangabad, Gaya, Jehanabad).

## 📊 Features
- **District Drilldown:** Individual district viewports displaying block-level coverage, team deployments, and task fulfillment.
- **Zero-Dependency Runtime:** Pure vanilla JavaScript and HTML for instant load times and offline accessibility.
- **Responsive Layout:** Mobile-friendly dashboard architecture with accessible metric cards and progress indicators.

## 🚀 Local Run
Simply open `arwal.html` or `aurangabad.html` in any web browser.
